# GloveAR · VONGOLA 手套实时叠加

浏览器里的实时手部 AR 演示：通过摄像头和 MediaPipe Hands 追踪双手，把 3D 手套模型重定向到真实手上；握拳时让手套发出暖色微光，或点燃程序化的大空火焰（两种模式可切换），张手熄灭。

纯静态前端，无后端、无构建步骤。

## 特性

- **双手追踪**：MediaPipe Hands 识别左右手，两只手套各自贴合
- **骨骼重定向**：用 21 个手部关键点驱动手套骨骼，含镜像处理
- **手势识别**：用逐指关节夹角算每根手指的弯曲度，配合迟滞与防抖识别
  握拳 / 张手 / 指向 / 比耶 / 点赞 / 六 / 手枪 / 改枪（手枪 + 中指）
- **双手组合 · 零点突破**：两只手的对应指尖相碰（左拇↔右拇、左食↔右食），
  且整体大致左右对称时，状态栏显示「零点突破」（不要求改枪，其他手指姿势不限）；
  同时两只手套整体泛起强暖光，接触轴中点凝聚橙色气团并向四周炸开，
  两者都以每秒 1 次的节奏循环（两种特效模式下都会生效）
- **手势调试面板**：`?gesture=1` 或按 `G` 显示每指弯曲度、伸/屈状态与当前手势
- **两种特效模式**：
  - 模式 1 · 手套微光（默认）：握拳只让手套边缘透出暖色光，不出现火球、光晕或粒子
  - 模式 2 · 球形火焰：握拳在拳头周围点燃程序化火焰球
  - 左下角「手套微光 / 球形火焰」切换按钮或 URL 参数切换
- **手势驱动点火**：点亮 / 点燃由手势层的「握拳」判定驱动（逐指迟滞 + 0.15s 防抖）；
  张开手掌或其他手势都会熄灭（放拳时火焰强弱仍随拳的松紧变化）
- **程序化火焰球**（`js/flame3d.js`，模式 2）：
  - 橙色边缘 + 内部金→橙红渐变的半透明球体
  - 3D 噪声生成向上卷动的内部火舌
  - 顶部按角度分裂出火苗尖端，会舔动、外扩
  - 手快速移动时火焰沿运动方向拉伸、横向收紧并轻微拖后
  - 点燃时上浮、缓慢浮动
- **仅火焰 bloom**：火焰单独渲染到一层再叠加辉光，亮银色手套不会被泛光糊掉
- **2D 光晕与粒子**：掌心光晕、余烬、火花补充氛围
- **常驻颤抖波形**：左下角面板实时显示左右手掌心微动的波形，自动纵轴，
  并给出合成 RMS 抖幅（手长归一化）、估算频率与覆盖率；与测量协议无关，
  自由模式下也持续运行
- **测量协议与指标**：内置「握拳张开 / 旋前旋后」两个 10 秒任务预设，
  3 秒倒计时后自动录制、自动停止；导出的 JSON 附带开合次数、频率、
  幅度或关节活动范围、节奏变异，以及覆盖率与中途换手等质量标记

## 最短用法

在终端运行 `node server.js`，浏览器打开 <http://127.0.0.1:8741/> 并允许摄像头，把手放进画面即可。握拳点亮或点火，张手熄灭；左下角切换「手套微光 / 球形火焰」。要记录动作时，在底部选择「握拳张开」或「旋前旋后」，再点「开始」。

## 运行

需要 Node.js（仅用于静态文件服务）和支持摄像头权限的现代浏览器（推荐 Chrome / Edge）。

```bash
node server.js
```

打开 <http://127.0.0.1:8741/>，允许摄像头权限即可。

Windows 下也可以直接双击 `start.cmd`：它会启动服务并打开浏览器。

## 操作

| 操作 | 效果 |
| --- | --- |
| 握拳 | 手套发光（模式 1）或点燃火焰（模式 2） |
| 张开手掌 | 熄灭 |
| 左下角「手套微光 / 球形火焰」按钮 | 切换特效模式 |
| 右下角 ⇄ 按钮 | 切换左右手镜像 |
| `G` 键 | 开关手势调试面板 |
| `C` 键 | 复制当前双手手势数据（调阈值用） |
| `S` 键 | 开关实时信号检视面板（阈值校准时用） |
| `M` 键 | 自由模式：开始 / 停止记录；已选测量协议时：开始 / 取消 |
| `Esc` 键 | 取消正在倒计时或录制的测量协议 |
| 底部协议栏 | 选择「自由 / 握拳张开 / 旋前旋后」，再点「开始」 |

## 数据采集与测量协议

按 `M` 自由记录，再按一次停止并下载 `glovear-session-*.json`。无论哪种方式，
JSON 都包含约 30Hz 的左手/右手 21 个 MediaPipe 归一化关键点（x/y/z）、时间戳、
手别与置信度、检测延迟，以及视口尺寸和运行环境。

底部协议栏选择一个任务后点「开始」（或按 `M`）：3 秒倒计时 → 录制固定时长 →
自动停止并下载 JSON，右侧面板显示本次指标。倒计时或录制中可按 `Esc` 取消。

| 协议 | 动作 | 指标 |
| --- | --- | --- |
| 握拳张开 | 反复握拳再完全张开 | 开合次数、频率、幅度、间隔变异系数 |
| 旋前旋后 | 手掌朝上 / 朝下翻转，前臂保持不动 | 翻腕次数、频率、活动范围（度）、周期变异系数 |
| 自由 | 任意活动 | 仅原始数据 |

流程控制集中在 `js/protocol-job.js`，指标统一从同一份原始关键点序列离线计算（`js/protocols.js`）。

数据流：摄像头帧 → `hands.js` 重定向 / 手势 → `measure.js` 以 30Hz 记录原始关键点
→ `protocol-job.js` 控制倒计时与录制窗口 → `protocols.js` 计算指标 → 导出 JSON。
`signal.js` / `signal-panel.js` 复用同一套提取函数实时显示波形，因此面板读数与导出结果一致。幅度以手部尺寸
（腕点→中指掌指关节）为单位，因此与距离镜头远近无关；左右手分别计算，并附带
覆盖率、最大丢帧和「中途换手」质量标记。JSON 中的 `metrics` 字段是派生结果，
`samples` 原始序列保持不变，指标参数调整后可以重新计算。

左下角还有一个与协议无关的常驻颤抖面板：对掌心（腕点 + 四个掌指关节）的
x/y 位移做 2Hz 二阶高通，去掉主动移动后显示最近 5 秒波形；抖幅为 x/y 合成
RMS，以手长归一化，因此不受镜头远近影响。面板只用于实时观察，不写入导出 JSON。
30Hz 采样与单目摄像头只能作为训练参考，不能用于诊断。

调阈值时可打开实时信号检视面板（`S` 键或 `&signal=1`）：选择协议后立即开始采样，
左右手各显示最近 5 秒的指标波形、p5–p95 包络、幅度下限带、已识别次数与频率，
以及覆盖率和最大丢帧。面板不依赖录制，可在按「开始」之前确认动作幅度是否足够。

数据只在本地生成，不会上传。当前指标仅供训练和研究参考，未经临床验证，
不能用于诊断。

## 调试参数

在 URL 后追加参数：

| 参数 | 作用 |
| --- | --- |
| `?mode=glow` | 模式 1 · 手套微光（默认；也可用 `?mode=1`） |
| `?mode=flame` | 模式 2 · 球形火焰（也可用 `?mode=2`） |
| `?selftest=1` | 用合成手做重定向自检，不启用摄像头 |
| `&two=1` | 加入第二只合成手 |
| `&fist=1` | 合成手握拳（用于检查点火） |
| `&six=1` / `&gun=1` / `&gunv=1` | 合成手摆「六」/「手枪」/「改枪」 |
| `&zero=1` | 合成双手摆「零点突破」 |
| `&fire=1` | 强制满强度（用于截图） |
| `&gesture=1` | 显示手势调试面板（每指弯曲度与当前手势） |
| `&signal=1` | 显示实时信号检视面板 |
| `&tremor=0` | 隐藏左下角的常驻颤抖面板（默认显示） |
| `&protocol=open_close` | 预选测量协议；可选 `pronation_supination` |
| `?raw=1` | 显示手套绑定姿态 |

例如：

```text
http://127.0.0.1:8741/?selftest=1&two=1&fist=1&fire=1
```

```text
index.html          页面与 importmap
server.js           极简静态服务器（仅监听 127.0.0.1）
start.cmd           Windows 启动脚本
js/
  app.js            启动、渲染管线与帧循环编排
  config.js         可调参数（阈值、平滑、辉光强度等）
  coords.js         关键点 -> 屏幕 / 世界坐标的唯一映射
  view.js           视频铺满窗口的 cover 适配矩形（渲染与离线分析共用）
  hands.js          双手槽位、逐帧更新、零点突破锚点
  ui.js             状态栏、模式按钮、镜像与手势调试面板
  measure.js        原始关键点时序记录与 JSON 导出
  protocols.js      测量协议定义与指标分析（纯函数，可离线复用）
  protocol-job.js   引导式测量流程（倒计时、定时录制、分析、导出）
  rolling-window.js 测量窗口容器（采样点、覆盖率、最大丢帧）
  waveform.js       两个波形面板共用的网格 / 空态 / 折线绘制
  signal.js         实时信号窗口（面板与离线分析共用同一套提取）
  signal-panel.js   信号检视面板的 DOM 与波形绘制
  tremor.js         常驻颤抖监测（掌心高通微动、RMS 幅度）
  tremor-panel.js   常驻颤抖波形面板
  hand-tracker.js   摄像头与 MediaPipe Hands
  gesture.js        逐指弯曲度、手势分类与双手组合
  retarget.js       关键点 -> 手套骨骼重定向
  flame3d.js        程序化火焰球（着色器）
  zero-burst.js     零点突破的气团凝聚与爆开
  glove-glow.js     模式 1 的手套边缘暖光
  fire.js           2D 光晕、余烬、火花与点火强度曲线
  selftest.js       合成手自检
css/style.css       页面样式
glove.glb           手套模型
vendor/             three.js 及其 addons（MIT）
```
