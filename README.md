# GloveAR · VONGOLA 手套实时叠加

浏览器里的实时手部 AR 演示：通过摄像头和 MediaPipe Hands 追踪双手，把 3D 手套模型重定向到真实手上；握拳时让手套发出暖色微光，或点燃程序化的大空火焰（两种模式可切换），张手熄灭。

纯静态前端，无后端、无构建步骤。

## 特性

- **双手追踪**：MediaPipe Hands 识别左右手，两只手套各自贴合
- **骨骼重定向**：用 21 个手部关键点驱动手套骨骼，含镜像处理
- **手势识别**：用逐指关节夹角算每根手指的弯曲度，配合迟滞与防抖识别
  握拳 / 张手 / 指向 / 比耶 / 点赞 / 六 / 手枪 / 改枪（手枪 + 中指）
- **双手组合 · 零点突破**：两只手的对应指尖相碰（左拇↔右拇、左食↔右食），
  且整体大致左右对称时，状态栏显示「零点突破」（不要求改枪，其他手指姿势不限）；
  同时两只手套整体泛起强暖光，接触轴中点凝聚橙色气团并向四周炸开，
  两者都以每秒 1 次的节奏循环（两种特效模式下都会生效）
- **手势调试面板**：`?gesture=1` 或按 `G` 显示每指弯曲度、伸/屈状态与当前手势
- **两种特效模式**：
  - 模式 1 · 手套微光（默认）：握拳只让手套边缘透出暖色光，不出现火球、光晕或粒子
  - 模式 2 · 球形火焰：握拳在拳头周围点燃程序化火焰球
  - 左下角「手套微光 / 球形火焰」切换按钮或 URL 参数切换
- **握拳点火 / 张手熄灭**：带滞回阈值和防抖，避免临界手势来回闪烁
- **程序化火焰球**（`js/flame3d.js`，模式 2）：
  - 橙色边缘 + 内部金→橙红渐变的半透明球体
  - 3D 噪声生成向上卷动的内部火舌
  - 顶部按角度分裂出火苗尖端，会舔动、外扩
  - 手快速移动时火焰沿运动方向拉伸、横向收紧并轻微拖后
  - 点燃时上浮、缓慢浮动
- **仅火焰 bloom**：火焰单独渲染到一层再叠加辉光，亮银色手套不会被泛光糊掉
- **2D 光晕与粒子**：掌心光晕、余烬、火花补充氛围

## 运行

需要 Node.js（仅用于静态文件服务）和支持摄像头权限的现代浏览器（推荐 Chrome / Edge）。

```bash
node server.js
```

打开 <http://127.0.0.1:8741/>，允许摄像头权限即可。

Windows 下也可以直接双击 `start.cmd`：它会启动服务并打开浏览器。

## 操作

| 操作 | 效果 |
| --- | --- |
| 握拳 | 手套发光（模式 1）或点燃火焰（模式 2） |
| 张开手掌 | 熄灭 |
| 左下角「手套微光 / 球形火焰」按钮 | 切换特效模式 |
| 右下角 ⇄ 按钮 | 切换左右手镜像 |
| `G` 键 | 开关手势调试面板 |
| `C` 键 | 复制当前双手手势数据（调阈值用） |

## 调试参数

在 URL 后追加参数：

| 参数 | 作用 |
| --- | --- |
| `?mode=glow` | 模式 1 · 手套微光（默认；也可用 `?mode=1`） |
| `?mode=flame` | 模式 2 · 球形火焰（也可用 `?mode=2`） |
| `?selftest=1` | 用合成手做重定向自检，不启用摄像头 |
| `&two=1` | 加入第二只合成手 |
| `&fist=1` | 合成手握拳（用于检查点火） |
| `&six=1` / `&gun=1` / `&gunv=1` | 合成手摆「六」/「手枪」/「改枪」 |
| `&zero=1` | 合成双手摆「零点突破」 |
| `&fire=1` | 强制满强度（用于截图） |
| `&gesture=1` | 显示手势调试面板（每指弯曲度与当前手势） |
| `?raw=1` | 显示手套绑定姿态 |

例如：

```text
http://127.0.0.1:8741/?selftest=1&two=1&fist=1&fire=1
```

## 目录结构

```text
index.html          页面与 importmap
server.js           极简静态服务器（仅监听 127.0.0.1）
start.cmd           Windows 启动脚本
js/
  app.js            场景、渲染循环、bloom 合成
  config.js         可调参数（阈值、平滑、辉光强度等）
  hand-tracker.js   摄像头与 MediaPipe Hands
  gesture.js        逐指弯曲度与手势分类
  retarget.js       关键点 -> 手套骨骼重定向
  flame3d.js        程序化火焰球（着色器）
  zero-burst.js     零点突破的气团凝聚与爆开
  glove-glow.js     模式 1 的手套边缘暖光
  fire.js           2D 光晕、余烬、火花与手势状态
  selftest.js       合成手自检
css/style.css       页面样式
glove.glb           手套模型
flame.glb           早期网格火焰实验，当前渲染不再使用
tools/flame_build.py  生成 flame.glb 的 Blender 脚本
vendor/             three.js 及其 addons（MIT）
```
